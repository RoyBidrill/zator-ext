# Ручная проверка

Автотесты не открывают браузер. Это то, что они не покрывают.

1. `chrome://extensions` → режим разработчика → «Загрузить распакованное» → папка `zator-ext`.
2. Открыть любой сайт. Кнопка расширения открывает попап и не создаёт вкладку.
3. В попапе сверху Проблемы, ниже ОК, затем Игнор. Заголовок секции сворачивает её. Ответ 400/500 лежит в ОК. Поздний обрыв уже показанного хоста, не закрывая попап, сам переносит строку в Проблемы и пишет короткую причину: таймаут, reset, обрыв http/2. Следующий ответ HTTP возвращает её в ОК. Значок активной вкладки показывает число проблемных, пока не идёт проба.
4. Кнопка с буфером открывает меню. Для `00.img.avito.st` пункты: `^00.img.avito.st`, `00.img.avito.st`, `img.avito.st`, `avito.st`. Звёздочки и голого `st` нет. В буфер попадает только строка правила.
5. «Скрыть» переносит строку в Игнор. Закрыть попап, открыть снова — строка всё ещё в Игноре.
6. «Настройки» открываются отдельной вкладкой.
7. Добавить `0.0.0.0` уже есть по умолчанию. Ввести `10.0.0.0/8` — отказ, маска не принимается.
8. «Обновить» у списка качает копию. Выключить тумблер — пометка этого списка в попапе пропадает без перезапуска браузера.
9. Отключить сеть и нажать «Обновить» — старая копия на месте, видна ошибка.
10. Пометить хост, закрыть попап, открыть снова — пометка на месте. Смена только хэша пометку не снимает. Уход на другой path снимает.
11. «Начать» обновляет эту же вкладку. Значок показывает `N/M`. Попап другой вкладки вторую «Начать» не даёт: значок один на окно.
12. Во время прогона секции ОК, Проблемы и Игнор не пустеют из-за самого прогона.
13. Таймаут документа без числового кода — документ попытки красный. Обрыв загрузки расширением или блокировщиком (`ERR_ABORTED`, `ERR_BLOCKED_BY_CLIENT`) — попытка недействительна и в большинство не входит.
14. «Остановить» до следующей попытки — записанные попытки на месте, итог «остановлен», значок `!` на красном, не зелёный.
15. Уход на другой path во время прогона — «вкладка ушла». Закрытие вкладки — «вкладка закрыта».
16. Пауза длиннее 30 секунд не обнуляет прогон: следующая попытка начинается сама.
17. Открыть YouTube, дождаться видео, открыть попап. У хоста виден разброс времени (мин / сред / хвост), не одна метка «N мс» только в Проблемах. Чанки без Content-Length: время есть, строки скорости нет. Если заголовок есть у части запросов, счётчик скорости не больше счётчика времени. Перезагрузка фона обнуляет журнал — это не регрессия.
18. На YouTube в Network отфильтровать `googlevideo` и найти красные `(canceled)` у `videoplayback` рядом с 200 того же хоста. В попапе хост остаётся в ОК, под именем — `отменено N из M`. Хост, у которого были только отмены и ни одного ответа, в секциях не появляется.
